# Glossary

**Level:** reference · for looking a word up

**One line:** The terms this library uses, each in a sentence or two, with the page that explains it.

**ABC technique** — Albert Ellis's: an Antecedent prompts a Belief, which leads to a Consequence; change the belief and the consequence changes. See [learned helplessness](03_Believing_You_Can/learned_helplessness/README.md).

**Attribution bias** — putting our own failures down to circumstances and other people's to character. See [mindset and motivation](05_Body_and_Brain/mindset_and_motivation/README.md).

**Automaticity** — a step practised until it takes no thought, and so no place in working memory. See [cognitive load](02_Making_It_Stay/cognitive_load/README.md).

**Bloom's taxonomy** — six levels of working with an idea, in the 2001 revision: remembering, understanding, applying, analyzing, evaluating, creating (in 1956: knowledge, comprehension, application, analysis, synthesis, evaluation). See [studying vs learning](01_Knowing_What_You_Know/studying_vs_learning/README.md).

**Brier score** — the mean of (confidence − outcome)², with outcome 1 for right and 0 for wrong: 0 is perfect, and saying 50% every time scores 0.25. It is a proper scoring rule, so its expected value is smallest when you report what you really believe. See [metacognition](01_Knowing_What_You_Know/metacognition/README.md).

**Buffer** — time held in reserve in a plan, because task-time errors all point the same way. See [the buffer hour](04_Planning_the_Work/the_buffer_hour/README.md).

**Calibration** — how well confidence matches results: a calibrated learner's 90% answers are right about 9 times in 10. See [metacognition](01_Knowing_What_You_Know/metacognition/README.md).

**Chunk** — a unit you already know well enough to hold as one: a word rather than its letters, 1492 rather than four digits. Working memory holds about four. See [cognitive load](02_Making_It_Stay/cognitive_load/README.md).

**Cognitive load** — Sweller's word for how much working memory a task takes: intrinsic (the task itself), extraneous (distractions that do not help), germane (the effort of building chunks and schemas). See [cognitive load](02_Making_It_Stay/cognitive_load/README.md).

**Consolidation** — the stabilising of a new memory, within hours at the synapse and over weeks across brain regions; sleep does much of it. See [how memory works](05_Body_and_Brain/how_memory_works/README.md) and [sleep](05_Body_and_Brain/sleep/README.md).

**Cutoff** — the value of a continuous quantity on one side of which a yes/no word applies. See [day or night](03_Believing_You_Can/day_or_night/README.md).

**Desirable difficulty** — Bjork's term for a condition that makes learning harder now and better later: retrieval, spacing, interleaving. See [how memory works](05_Body_and_Brain/how_memory_works/README.md#desirable-difficulties).

**Egocentric bias** — remembering our part in a success as larger, and in a failure as smaller, than it was. See [mindset and motivation](05_Body_and_Brain/mindset_and_motivation/README.md).

**Evidence grade** — this library's substitute for a program where none can check a claim: well established, good evidence, weak, speculative. See [05_Body_and_Brain](05_Body_and_Brain/README.md).

**Forgetting curve** — Ebbinghaus's finding that memory fades fast at first and then slowly. See [spaced retrieval](02_Making_It_Stay/spaced_retrieval/README.md).

**Growth mindset** — Dweck's term for believing ability can be developed; its interventions move grades a little. See [mindset and motivation](05_Body_and_Brain/mindset_and_motivation/README.md).

**Hypercorrection** — errors made with high confidence are the easiest to correct once feedback arrives. Not the same as pretesting. See [how memory works](05_Body_and_Brain/how_memory_works/README.md#desirable-difficulties).

**Imposter syndrome** — having succeeded and believing you are about to be found out; the cure is the record of results. See [mindset and motivation](05_Body_and_Brain/mindset_and_motivation/README.md).

**Interference** — a new, weak memory trace overwritten by the next thing learned. See [how memory works](05_Body_and_Brain/how_memory_works/README.md).

**Interleaving** — mixing kinds of problems in one session instead of practising one kind at a time, so that choosing the method is rehearsed. See [interleaving](02_Making_It_Stay/interleaving/README.md).

**Learned helplessness** — not trying to escape a bad situation because trying failed before, even when escape is now possible. See [learned helplessness](03_Believing_You_Can/learned_helplessness/README.md).

**Long-term potentiation (LTP)** — the lasting strengthening of a synapse that fires repeatedly; the cellular mechanism usually given for memory. See [brain chemistry](05_Body_and_Brain/brain_chemistry/README.md).

**Metacognition** — John Flavell's word (1976) for thinking about your own thinking, including the ability to judge accurately how much you have learned, the one part a program can measure. See [metacognition](01_Knowing_What_You_Know/metacognition/README.md).

**Planning fallacy** — underestimating how long a task will take, even with experience of past overruns. See [the buffer hour](04_Planning_the_Work/the_buffer_hour/README.md).

**Pretesting effect** — guessing the answer before studying helps, even when the guess is wrong. See [how memory works](05_Body_and_Brain/how_memory_works/README.md#desirable-difficulties).

**Process goal and end goal** — "study three hours a day" and "get an A"; the first gets you to the second and is the one people forget. See [goals and schedules](04_Planning_the_Work/goals_and_schedules/README.md).

**Rule of succession** — Laplace's estimate after s successes in n tries: (s + 1)/(n + 2). See [learned helplessness](03_Believing_You_Can/learned_helplessness/README.md).

**Schema** — organised knowledge you can pull up whole, one chunk with slots. See [cognitive load](02_Making_It_Stay/cognitive_load/README.md).

**Self-efficacy** — Bandura's term for how far you believe you can succeed at a given task. See [mindset and motivation](05_Body_and_Brain/mindset_and_motivation/README.md).

**SMART** — specific, measurable, achievable, relevant, timely: a mnemonic for the properties a goal needs. See [goals and schedules](04_Planning_the_Work/goals_and_schedules/README.md).

**Sorites** — the paradox of the heap: one grain never makes a heap, so there are no heaps; for dusk, one minute never makes night. See [day or night](03_Believing_You_Can/day_or_night/README.md).

**Spacing effect** — the same number of reviews works better spread out than crammed together, because a review strengthens memory most when some has been forgotten. See [spaced retrieval](02_Making_It_Stay/spaced_retrieval/README.md).

**Study cycle** — McGuire's week: preview, class, review the same day, intense study sessions, self-test. See [spaced retrieval](02_Making_It_Stay/spaced_retrieval/README.md#the-study-cycle-spacing-built-into-a-week).

**Testing effect** — retrieving something from memory makes it last longer than reading it again for the same time. See [spaced retrieval](02_Making_It_Stay/spaced_retrieval/README.md).

**Working memory** — the few chunks you can hold and work on at once; about four. See [cognitive load](02_Making_It_Stay/cognitive_load/README.md).

**Zone of proximal development** — Vygotsky's band between too easy and too hard, where learning is fastest. See [how memory works](05_Body_and_Brain/how_memory_works/README.md).
