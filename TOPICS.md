# Topic map

**Level:** reference · for finding a page by subject instead of by chapter

**One line:** The sidebar lists the chapters A to Z; this page sorts every page by subject into branches, then follows the threads that run between chapters.

The chapter numbers are the suggested reading order, and each chapter is one argument, so inside a chapter the lessons are best read in order. This page is the other way in. A page sits once in the tree, where it belongs; a ↪ marks a page from another branch that is worth reading alongside. The build checks that every page appears here.
